# وصّلها — تطبيق Flutter (نسخة أصلية)

نسخة Flutter أصلية من تطبيق وصّلها، بتتصل بنفس مشروع Supabase اللي الموقع
(`../src`) بيستخدمه بالظبط — نفس الجداول، نفس الـ RPCs، نفس الـ Edge
Functions. مفيش أي تغيير في الباك إند.

## ليه Flutter بدل Capacitor؟

الموقع متغلّف بالفعل كتطبيق موبايل عبر Capacitor (WebView) — شغّال وجاهز
للنشر. النسخة دي بديل **أصلي حقيقي** (native) لأداء وسرعة أفضل، مش تعديل
على النسخة الحالية.

## الحالة الحالية (المرحلة الأولى)

**جاهز وشغّال:**
- تسجيل الدخول / إنشاء حساب (`lib/features/auth/`)
- المشاوير: بحث عناوين، حساب الأجرة، إرسال الطلب، تتبع لحظي (`lib/features/rides/`)
- المحفظة: الرصيد، إيداع، سحب، تحويل، سجل المعاملات (`lib/features/wallet/`)
- الواجهة الرئيسية بشريط تنقّل من 6 تبويبات (مطابقة لـ `BottomNav.astro`)

**قريباً (نفس النمط، جاهز للتوسعة):**
- توصيل الطرود والمستندات
- خدمة دليفري العامة
- لوحة تاجر/سائق أساسية

## التشغيل

```bash
flutter pub get
flutter run              # على جهاز/محاكي متصل
flutter build apk        # نسخة أندرويد
flutter build ios        # نسخة iOS (على ماك فقط)
```

## البنية

```
lib/
  core/               # اتصال Supabase، الجلسة، أدوات مشتركة (تليفون، باسورد)
  features/
    auth/             # تسجيل دخول / حساب جديد
    home/             # الواجهة الرئيسية + شريط التنقل
    rides/            # المشاوير
    wallet/           # المحفظة
  shared/widgets/     # عناصر مشتركة (شاشة "قريباً" للميزات الجاية)
```

كل ملف فيه تعليق بيوضّح مصدره المطابق في الموقع (مثلاً "ported 1:1 from
src/utils/phone.ts") — أي تعديل في القاعدة (الأجرة، قواعد الباسورد،
التحقق من الجوال) لازم يتزامن في المكانين.
